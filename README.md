# Sounavy — GaIA · Opera Vox

Site oficial: **https://www.sounavy.com**

GaIA: IA pessoal soberana que nasce no telefone. Opera Vox: a voz como sistema operacional.
Projeto de inclusão digital — Antônio Alberto Lopes Elias (Sounavy).

## O que tem aqui

| Arquivo | Função |
|---|---|
| `index.html` | O site completo (uma página só, sem dependências externas além das fontes) |
| `manifest.json` | Permite instalar como aplicativo no celular ("Adicionar à tela inicial") |
| `sw.js` | Service worker — o site funciona offline depois da primeira visita |
| `icon-*.png` | Ícones do aplicativo (a bolinha) |
| `CNAME` | Liga este repositório ao domínio www.sounavy.com |

## Como publicar (GitHub Pages)

1. Este repositório precisa estar **Público**.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: **main** → Save.
3. Settings → Pages → Custom domain: **www.sounavy.com** → Save → marcar **Enforce HTTPS** quando liberar.
